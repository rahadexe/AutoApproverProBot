Four engineering guarantees.

Built directly on Telegram Bot API 8.0 without userbots or scrapers.

Sub-40ms edge execution

When a visitor submits a join request, Telegram dispatches a webhook. AutoApprover processes the payload and returns approval in under 40 milliseconds.

DM captcha verification

Scrapers and automated user accounts are held in pending queue until they interact with an inline verification button inside their private bot chat.

Permanent member ledger

Every user ID, handle, and join timestamp is saved to an internal SQLite ledger. Channel admins can export subscriber data or dispatch announcements.

Zero account ban risk

The engine operates exclusively through Telegram's official approveChatJoinRequest method. No account credentials or MTProto session files required.

Frequently asked questions

Type to filter common questions and implementation details.

Is AutoApprover Pro completely free? +
Yes. The engine runs on serverless architecture with minimal resource overhead. You can connect your channels and approve unlimited join requests without subscriptions.
Can Telegram restrict my channel for using this? +
No. The engine operates entirely through Telegram's official Bot API endpoint (approveChatJoinRequest). It adheres to rate limits and violates no platform rules.
How does the bot message users with private DM settings? +
When a user requests to join an admin-approval link, Telegram temporarily opens an authorized communication window allowing the channel's bot administrator to send verification prompts.
What is the difference between Captcha Gate and Instant Mode? +
Captcha Gate asks users to tap a verification button in DM before admitting them to the group. Instant Mode admits applicants in approximately 40 milliseconds without any button tap.
Does it work on supergroups as well as broadcast channels? +
Yes. Both broadcast channels and supergroups with join request links are fully supported.
